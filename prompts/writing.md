# 精读与导读写作规则

适用于 ⭐ 精读卡片（`analysis`、`title_zh`）和今日导读（`overview.guide`）。精读必须在读完 PDF 全文后再写，不能只依据摘要。

## 精读卡片

- **标题**（`title_zh`）：直接写出论文最重要的发现，带上数字。示例：「RL 让搜索 Agent 涨了 30 个点，其中"更会搜"只占不到 15%」。不要直译论文原标题。
  **不超过 35 个字**（英文单词、数字各按 1 个字计），只放一个最关键的数字；补充说明留给正文。
- **长度**：和摘要相当，约 400–600 字，分 3–4 段。**超过 650 字必须删减**。最常见的超长原因是数字堆砌：每段只留最能说明问题的 2–3 个数字，其余放进图注或删掉。
- **段落顺序**：先讲这篇论文追问什么问题、答案是什么；再讲怎么做的；然后是最值得记住的发现；最后是保留意见和对实际工作的含义。
- **开头**：第一句就给结论或数字，不铺垫背景（不写"随着……发展"）。
- **方法**：用论文里的原词，一两句讲清楚。不评价方法本身，不写"方法很朴素""思路清晰"这类话。
- **简称和比喻**：第一次出现时要讲清楚指什么。例如不能只写"抽答案"，要写成"写出最终答案（填进 `<answer>` 标签的那一步）"。
- **第一人称**：只在确实有判断时用"我觉得""我怀疑"。
- **保留意见**：写成一句具体的话，指明缺了什么，比如模型规模、数据范围、缺少某个 baseline、没有测某个场景。
- **结尾**：说清楚对谁有什么实际影响，不做总结。
- **信息缺失时不写**，不用占位文字（比如没有机构就不写机构）。

## 行内标记

| 写法 | 用途 | 数量 |
|---|---|---|
| `==概念==` | 读者必须理解的核心概念、方法组成部分（例如论文定义的几个角色） | 每段 ≤ 3 |
| `**内容**` | 结论、风险、需要特别注意的地方 | 每段 ≤ 2 |
| `[[glossary-id]]` 或 `[[glossary-id\|显示文字]]` | 术语表里的词，鼠标悬停显示解释 | 新术语先加进 `site/data/glossary.json` |
| `[[@论文ID\|显示文字]]` | 链接到本期另一篇论文（导读里用） | — |

## 配图（`figures`）

图片直接引用论文 arXiv HTML 版（`https://arxiv.org/html/<id>v<n>`）里的图片文件，不下载、不转存。图片有两种写法，都要找：`<img src="….png">`，以及矢量图 `<object type="image/svg+xml" data="….svg">`（SVG 可以直接当图片用）。地址按相对路径拼成 `https://arxiv.org/html/<相对路径>`，写之前用 curl 确认返回 200。直接画在页面里的图（`<svg id="S3.F1.pic1" class="ltx_picture">`，通常是 TikZ）没有单独的文件：这类图写成 `{"src": "https://arxiv.org/html/<id>v<n>", "svg_id": "S3.F1.pic1", …}`，页面打开时会从 arXiv 取回这张 SVG 显示。没有 HTML 版本、或里面没有可用图片的论文就不配图。

- 每张图的字段：`{"src", "ref"（原文图号，如 "Figure 3"）, "caption_zh", "after"（可选）, "layout"（可选：full / side）}`。
- **正文配图 1–2 张**，写 `after: n`，表示放在第 n 段之后。图要和它前面那段文字直接相关：方法段配方法图，结果段配结果图。
- **其余值得看的图**不写 `after`，作为卡片底部的缩略图，点开是轮播。头条显示全部缩略图；其他 ⭐ 卡片默认显示前 3 张，其余收在 more 按钮里。所以把最重要的排在前面。
- **图注自己写**：一两句中文，说清楚"这张图在看什么、该看哪里"，不逐句翻译原文图注。可以补上正文里的关键数字，可以用 `==概念==`、`**重点**` 和术语标记。
- 宽图会占满一栏；接近方形的图（宽高比 < 1.4）会自动浮在右侧、正文绕排，一般不用写 `layout`。

## 今日导读

- **第一段固定写当天全部 ⭐ 论文**（包括头条）：每篇一句，说清楚它最核心的发现，或者读它时要注意什么。不要照抄精读卡片的标题，要换个角度说"为什么值得读"。
- **第二段写非 ⭐ 论文**：挑 3–5 篇值得一看的，写论文名加具体发现或数字。
- **总共最多 2 段、约 600 字以内**：⭐ 段落约 250 字，非 ⭐ 段落约 350 字。每篇论文一两句话，写具体发现或数字。
- 不写引导句（例如"有两篇可以对照着读"），直接进入具体内容。
- 论文名用 `[[@id|名字]]` 嵌在句子里。
- 当天没有 ⭐ 时，省略第一段。

## 禁用表达

值得注意的是、综上所述、总而言之、不难看出、具有重要意义、为……奠定了基础、开辟了新的方向、令人振奋、显著提升（后面没有数字）、未来值得进一步探索、三连排比（"高效、灵活且可扩展"）、堆叠的模糊措辞（"可能在一定程度上""或许有助于"）。

## 术语表（`site/data/glossary.json`）

收录有意思的词，或者不懂就看不下去的词。每个词全局只写一次，以后各期直接复用。解释写 1–3 句，用大白话说清楚它是什么、在这里有什么用。
